# Français – Découvertes Vokabeltrainer

Ein browserbasierter Vokabeltrainer zum Lernen von französischen und deutschen Vokabeln aus der Lehrbuchreihe Découvertes.

Das Projekt soll eine einfache und interaktive Möglichkeit bieten, Vokabeln direkt im Browser zu lernen und zu wiederholen.

## Features

- Übersichtliche Anzeige aller verfügbaren Vokabeln
- Karteikarten-Modus zum interaktiven Lernen
- Quiz-Modus zum Überprüfen des Wissens
- Tippen-Modus zum eigenständigen Eingeben von Übersetzungen
- Live-Modus für automatisches Vokabeltraining
- Lernen in beide Richtungen: Französisch → Deutsch und Deutsch → Französisch
- Suchfunktion zum schnellen Finden von Vokabeln
- Auswahl einzelner Abschnitte für gezieltes Lernen
- Optionale Audio-Unterstützung
- Fortschrittsanzeige während des Lernens

## Inhalt

Der Vokabeltrainer enthält aktuell Vokabeln aus:

- Découvertes – Unité 1
- Découvertes – Unité 2
- Découvertes – Unité 3

Die Vokabeln sind in verschiedene Abschnitte unterteilt, sodass gezielt bestimmte Bereiche gelernt werden können.

## Verwendung

Die Website läuft vollständig im Browser und benötigt keine Installation.

1. Website öffnen.
2. Einen Lernmodus auswählen.
3. Bei Bedarf einen bestimmten Abschnitt auswählen.
4. Die gewünschte Übersetzungsrichtung festlegen.
5. Mit dem Lernen beginnen.

## Technologien

Das Projekt basiert auf Standard-Webtechnologien:

- HTML
- CSS
- JavaScript

## Ziel des Projekts

Ziel dieses Projekts ist es, das Lernen von Vokabeln einfacher und interaktiver zu gestalten. Statt einer statischen Vokabelliste stehen verschiedene Lernmethoden zur Verfügung, die je nach Lernstil genutzt werden können.
